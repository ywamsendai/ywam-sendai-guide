## Summary

YWAM仙台では、言語と文化の学びを、共同生活と宣教における大切な一部として考えています。これは単に外国語の知識を増やすことではなく、異なる国や背景を持つ人々を理解し、敬意をもって迎え入れ、共に生きるための姿勢を育てることでもあります。

特に日本人メンバーにとっては、日本で海外からの人々を迎え、共に生活し、必要に応じて英語などを用いて助け合うことが、この学びの大切な一部になります。このページでは、YWAM仙台における言語と文化の学びの基本的な考え方を説明します。

## なぜ言語と文化の学びが大切なのですか？

言語と文化の学びが大切なのは、コミュニティのメンバーが次のように歩む助けになるからです。

- 異なる背景を持つ人々と、より敬意をもって関わること
- 思い込みではなく、相手をよりよく理解すること
- 日常生活や共同生活に、よりよく参加すること
- 不必要な誤解やすれ違いを減らすこと
- へりくだりと注意深さのうちに成長すること
- 日本において、より忠実に仕えること

YWAM仙台は、日本や他文化についての知識だけでなく、耳を傾けること、観察すること、そして敬意をもって学ぶ習慣を大切にしています。

## 日本人メンバーにとって、この学びは何を意味しますか？

日本人メンバーにとって、言語と文化の学びは、主に次のような意味を持ちます。

- 海外から来た人々を、日本で安心して過ごせるよう助けること
- 異なる国や文化の人々と共に生活し、働くことを学ぶこと
- 必要に応じて、簡単な英語や分かりやすい表現でコミュニケーションしようとすること
- 日本の生活習慣や文化的な前提を、相手に分かるように説明すること
- 自分にとって当たり前のことが、他の人には当たり前ではないと理解すること
- 将来、海外宣教や異文化の働きに遣わされる可能性に備えること

日本で育った人にとっては、自分の文化を説明することも大切な奉仕の一つです。相手に合わせて丁寧に伝えることは、ホスピタリティの一部でもあります。

## 英語に自信がなくても大丈夫ですか？

はい。英語に自信がなくても問題ありません。YWAM仙台は、すべての人に高い英語力や流暢さを求めているわけではありません。

大切なのは、次のような姿勢です。

- 完璧でなくても、伝えようとすること
- 短くても、親切に話そうとすること
- 分からないときに確認すること
- 必要に応じて、他の人の助けを借りること
- 恥ずかしさのために関わりを避けないこと

上手に話すことよりも、相手を歓迎しようとする心、助けようとする姿勢、そして学ぼうとする意志のほうが大切です。

## どのような英語が役立ちますか？

多くの場合、難しい英語よりも、短くて分かりやすい英語のほうが役立ちます。特に、あいさつ、案内、食事、確認、助けの申し出など、日常のホスピタリティに関わる表現はとても有用です。

たとえば、次のようなことを英語で少し言えるだけでも助けになります。

- あいさつすること
- 歓迎の気持ちを伝えること
- 食事や生活について案内すること
- 相手が困っていないか確認すること
- 分からないときに、ゆっくり話してもらうようお願いすること

大切なのは、複雑な表現ではなく、相手に伝わることです。

## 海外からの人々を迎えるときに役立つ簡単な表現はありますか？

はい。次のような短い表現は、海外からのゲストやコミュニティメンバーを迎えるときに役立ちます。

| 場面 | Simple English | 日本語 |
| :--- | :--- | :--- |
| あいさつ | Good morning | おはようございます |
| あいさつ | Hello | こんにちは |
| 歓迎 | Welcome to Sendai | 仙台へようこそ |
| 案内 | This way, please | こちらへどうぞ |
| 食事 | Please eat | どうぞ食べてください |
| 飲み物 | Would you like some coffee or tea? | コーヒーかお茶はいかがですか |
| 確認 | Are you okay? | 大丈夫ですか |
| 助け | Do you need help? | 何か手伝いが必要ですか |
| 聞き返し | Please say that again slowly | もう一度ゆっくりお願いします |
| 感謝 | Thank you | ありがとうございます |

これらはごく基本的な表現ですが、温かく迎えようとする気持ちを伝える助けになります。

## 共同生活の中で、言語と文化の学びはどのように起こりますか？

言語と文化の学びは、教室の中だけでなく、日々の共同生活の中で自然に起こることが多くあります。

たとえば、次のような場面です。

- 食事中の会話
- 礼拝や祈りの時間
- ゲストの受け入れ
- 掃除や実務を共に行う時間
- 地域の教会や近隣との関わり
- 買い物、交通機関、役所など日常生活の場面
- バイリンガルな案内やコミュニケーション

こうした学びは、多くの場合、少しずつ、関係の中で育っていきます。

## 文化の学びにおいて、どのような姿勢が大切ですか？

文化を学ぶうえで大切なのは、知識の量だけではなく、姿勢です。

YWAM仙台では、次のような姿勢を大切にしています。

- すぐに判断せず、まず耳を傾けること
- 違いを脅威ではなく学びの機会として受け止めること
- 自分のやり方だけが正しいと思わないこと
- 誤解が起きたときに、防御的になりすぎず対話すること
- 相手の背景や文脈を尊重すること
- 分からないことを恥とせず、学ぶこと

文化の学びは、固定的なステレオタイプを覚えることではありません。より注意深く、敬意をもって、教えられる者になることです。

## 間違いやすれ違いはあってもよいですか？

はい。間違いやすれ違いは、言語と文化の学びの中で自然に起こるものです。

大切なのは、恥ずかしさや失敗への恐れから引いてしまわないことです。完璧にできることよりも、教えられる姿勢のほうが重要です。

同時に、指摘や修正を受けたときには、それを拒まず、学び続ける姿勢が求められます。

## 日本で海外からの人々を迎えるうえで、どのような実践が役立ちますか？

次のような実践は、共同生活の中で特に役立ちます。

- 分かりやすく話すこと
- 相手が理解しているかを確認すること
- 日本の生活習慣やルールを丁寧に説明すること
- 必要に応じて、簡単な英語ややさしい日本語を使うこと
- 文化的な違いをすぐに善悪で判断しないこと
- 説明が必要なことを、面倒がらずに言葉にすること
- 相手の不安や戸惑いに気づこうとすること
- 助けを求めることも、助けを差し出すことも自然に行うこと

こうした小さな実践が、信頼と理解を育てます。

## この学びは、将来の海外宣教にもつながりますか？

はい。日本で海外からの人々を迎え、異文化の中で共に生きる経験は、将来の海外宣教や異文化の働きへの大切な備えにもなります。

たとえば、次のようなことを学ぶ機会になります。

- 自分の文化が絶対ではないことを知ること
- 分からない状況の中で、へりくだって学ぶこと
- 言葉が十分でなくても関係を築くこと
- 相手の立場に立って考えること
- 福音を、自分の慣れた形だけでなく、相手の文脈を尊重しながら分かち合うこと

海外に行く前から、このような姿勢を日本で養うことは大きな助けになります。

## YWAM仙台は、何を最も大切にしていますか？

YWAM仙台が言語と文化の学びにおいて最も大切にしているのは、上手さよりも姿勢です。

特に大切なのは、次のようなことです。

- へりくだり
- 傾聴
- 忍耐
- 敬意
- 学び続ける姿勢
- 相手を愛し、理解しようとする心

言語と文化の学びは、単なる実用的な技術ではありません。それは、共同生活、弟子訓練、ホスピタリティ、そして宣教の一部です。
