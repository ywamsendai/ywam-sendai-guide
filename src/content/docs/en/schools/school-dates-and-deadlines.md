## Summary

This page lists the current scheduled dates and application deadlines for YWAM Sendai schools.

All programs are bilingual in Japanese and English unless otherwise noted.

## What does this page include?

This page includes:
- upcoming school dates
- application deadlines
- planned future school timelines where available

Students should use the most current version of this page when planning an application.

**Status:** Applications open

| Event | Date |
| :--- | :--- |
| Arrival Day | September 24, 2026 |
| Lecture Phase Starts | September 25, 2026 |
| Outreach Phase Starts | December 21, 2026 |
| Graduation Day | February 19, 2027 |

### Application deadlines

- **International applicants requiring a visa:** June 26, 2026
- **International applicants not requiring a visa:** July 31, 2026
- **Domestic applicants (Japanese citizens or residents):** August 28, 2026
